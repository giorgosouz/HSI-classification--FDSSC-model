# HSI Classification with FDSSC on HyRANK

Implementation and training scripts for hyperspectral image classification on the HyRANK dataset using the FDSSC model.

## Repository contents
- `train.py`: training entry point
- `evaluate_model.py`: evaluation script
- `Utils/`: shared utilities
- `LICENSE`: license file

## Reference
- FDSSC paper: https://www.mdpi.com/2072-4292/10/7/1068

## Notes
- The repository keeps the training and evaluation workflow intentionally compact.
- Dataset-specific preparation is expected to be handled alongside the training scripts.
